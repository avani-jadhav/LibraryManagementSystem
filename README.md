# Library Management System

A console-based Library Management System developed using Java, JDBC, and MySQL.

## Features

- Add Book
- Display Books
- Search Book
- Update Book
- Delete Book
- Add Member
- Display Members
- Search Member
- Update Member
- Delete Member
- Issue Book
- Return Book
- Display Issued Books
- Show Available Books
- Show Returned Books

## Technologies Used

- Java
- JDBC
- MySQL
- Maven
- Eclipse IDE
